# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's **Report a vulnerability**
feature: open the repository's **Security** tab, select **Advisories**, and
choose **Report a vulnerability**.

Do not report security vulnerabilities in public issues or discussions.

Maintainers aim to acknowledge and respond to reports on a best-effort basis
within 7 days.
