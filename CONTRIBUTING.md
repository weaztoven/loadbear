# Contributing

Thanks for helping improve loadbear.

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Run `go test ./...` and `go test -race ./...` before opening a pull request.
4. Keep documentation and examples aligned with the code.

## Style

- Prefer small, focused packages.
- Keep Go idiomatic and dependency-light.
- Avoid adding frameworks or metrics clients.
